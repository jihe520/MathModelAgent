# 模型候选工具箱

本文件是候选模型工具箱，不是关键词到模型的机械映射表。

模型选择应依据问题机制、数据结构、假设、可解释性、计算规模、验证结果和业务约束综合决定，而不是机械套用某种“固定模型配方”。

## 经验与诊断，不做硬规则

- 不把“样本量 < 15 就必须用 GM(1,1)”当作硬规则。
- 不把“ARIMA 必须 50+”“随机森林必须 100+”“LSTM 必须 1000+”当作通用判定标准。
- 不把“AHP 超过 9×9 就必须拆分”为无条件规则。
- 不把“Monte Carlo 固定至少 10000 次”当作通用要求。
- 不把“步长减半结果变化 < 1% 才算收敛”当作唯一收敛判据。

这些更适合作为经验背景或诊断提示：是否适用要结合模型目标、数据特征、误差来源、解的稳定性和业务可解释性判断。

## 模型大分类与选型速查

### 五大题型识别

| 题型 | 核心问法 | 典型场景 |
| --- | --- | --- |
| 优化类 | 求最大/最小，资源怎么分配 | 路径规划、调度、选址、装箱、投资组合 |
| 预测类 | 预测未来数值或趋势 | 销量、人口、价格、时序分析 |
| 评价类 | 对多方案综合排序或打分 | 城市评级、供应商选择、方案比选 |
| 分类/聚类类 | 判断对象属于哪类，或自动分群 | 风险识别、客户分群、图像识别 |
| 机理/动力学类 | 描述系统随时间演化规律 | 传染病传播、生态系统、物理仿真 |

拿到题后先问：输出是一个数（优化）、一条序列（预测）、一个排名（评价）、一个类别标签（分类）还是一组微分方程（机理）？混合题型按主问题定主模型，子问题按实际需求叠加。

## 评价类模型

### 适用场景

- AHP：有专家经验、需要层次结构、需要解释权重来源。
- 熵权法：完全客观数据驱动，指标权重来自数据离散度。
- TOPSIS：多方案比较、排序、综合评价。
- 模糊综合评价：语言评价或模糊信息较多，适合主观评价场景。
- 灰色关联分析：数据少、信息不完整时可做辅助评价。
- DEA：评价投入产出效率。
- PCA + TOPSIS：指标高度相关、需降维和去冗余。
- AHP + 熵权组合：需要同时考虑主观经验和客观数据。

### 关键防错

- 先统一指标方向，再做归一化和权重计算。
- 需要说明无量纲化方法、指标差异和权重来源。
- AHP 的一致性检验必须结合具体矩阵意义解释，不是机械“CR < 0.1 即可接受”。
- TOPSIS 的贴近度不是百分制，不要直接当成百分比输出。
- 指标高度相关时，需考虑降维或组合分析方法，而不是堆叠多个评价模型。

## 预测类模型

### 适用场景

- 线性回归：变量间近似线性，且需要解释系数。
- 岭回归 / Lasso：多重共线性或高维特征选择。
- 时间序列模型：ARIMA、SARIMA、指数平滑、Prophet 等。
- 非线性回归与树模型：随机森林、XGBoost、CatBoost 等。
- 深度时序模型：LSTM/GRU 适用于复杂长序列、足够数据和更强非线性。
- 灰色预测：适合样本少、趋势相对稳定的短期趋势预测，但不适合复杂震荡序列。

### 关键防错

- 先判断问题是否为时序、回归、分类或混合任务，再决定模型。
- 预测类建模必须防数据泄漏：时间顺序切分、训练集 fit scaler 后再 transform 测试集。
- 残差、误差分布、外推风险和物理边界应一并检查。
- 任何“模型效果好”都需要结合任务缺失、解释性和稳定性分析。

## 优化类模型

### 适用场景

- 线性规划：线性目标与约束。
- 整数规划/混合整数规划：存在整数或 0-1 决策。
- 非线性规划：目标或约束为非线性。
- 动态规划：状态转移明确、适合最优子结构问题。
- 遗传算法、模拟退火、粒子群：复杂非凸或黑箱优化问题。
- NSGA-II：多目标优化，关注 Pareto 前沿。

### 关键防错

- 先保证可行性，再追求优化目标。
- 最大化问题必须明确目标变换方式，并在结果记录中说明还原逻辑。
- 约束方向、变量界限和变量类型必须对齐；整数解要重新验证可行性。
- 启发式方法需要多次独立运行和稳定性分析，不能依靠单次结果。
- 多目标模型不能直接对不同量纲目标简单相加，必须先归一化或进行 Pareto 分析。

## 机理/动力学类模型

### 常见模型

- Logistic 增长：适用于种群增长、市场渗透率等 S 曲线过程。
- SIR / SEIR：适用于传染病和谣言传播等群体模型。
- Lotka-Volterra：适用于捕食者-猎物或竞合系统。
- ODE / PDE：适用于连续时间动态系统和扩散过程。
- 元胞自动机 / 马尔可夫链：适用于离散状态演化和随机过程。

### 关键防错

- 状态变量必须有物理或业务含义，并标注单位。
- 初始条件和边界条件要明确。
- 数值求解需检查步长、稳定性、守恒量和参数拟合区间。
- 不能因为“看起来像机理模型”就忽略验证与拟合质量。

## 图论与网络类模型

### 常见方法

- 单源最短路：Dijkstra（非负权）或 Bellman-Ford（允许负权）
- 最小生成树：Prim / Kruskal
- 最大流与最小费用最大流：适合运输、分配和流量控制问题
- TSP / VRP：适合路径与配送问题
- 二分图匹配：适合指派、分配和资源匹配问题

### 关键防错

- 明确有向/无向、容量、权重和连通性。
- 不能忽略流量守恒、子回路和可行路径约束。
- 图规模大时要选择合适算法，避免使用不适合的全局算法。

## 统计分析与机器学习

### 常见方法

- t 检验、ANOVA、Mann-Whitney U：均值或分布差异检验。
- 相关分析：Pearson、Spearman 等，需结合数据特征和图像诊断解释。
- 回归：线性回归、岭回归、Lasso、逻辑回归等。
- 分类：随机森林、SVM、XGBoost、逻辑回归等。
- 聚类：K-means、DBSCAN、层次聚类等。

### 关键防错

- 相关性和检验结论不能看作唯一真理，需要与模型假设、样本量和数据形态综合判断。
- 训练/验证/测试划分必须明确，避免测试集参与调参。
- 过拟合应通过交叉验证、稳定性和误差分布评估，而非仅凭训练集表现。
- 不能把“模型精度高”当作建模合理性的充分条件，仍需结合解释性、机制性和业务可行性进行评估。

## 选型的基本原则

- 优先相信问题机制，而不是“模型热词”。
- 先判断任务类型与数据结构，再决定候选集合。
- 每一种方法都要从业务可解释性、可验证性、可实现性和计算规模考虑。
- 模型目录只是候选参考，不是最终答案，也不是机械映射表。
