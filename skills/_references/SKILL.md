# _references

本文件夹是共享规范知识库，不是可独立执行的 skill。

当前 v0.1 采用分层知识结构：

- `modeling_core_norms.md`：长期稳定的数学建模原则
- `model_catalog.md`：模型候选工具箱
- `common_failure_cases.md`：常见失误案例库
- `competition_rules/cumcm.md`：CUMCM 规则（按官方通知更新）

`math_modeling_norms.md` 现阶段仍保留为 legacy 回退参考，不删除，不改写，以兼容现有引用和历史内容。其他 skills 在需要领域判断时，优先读取新文件，不要手动触发此 skill。
